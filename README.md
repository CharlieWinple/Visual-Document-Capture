# Visual Document Capture

**简体中文** | [English](README.en.md)

面向 Windows 11 的本地、视觉优先文档采集项目。从用户选定区域的可见像素恢复连续内容和原始分页，不读取 DOM、浏览器内部数据、PDF.js 或网络原始资源。

**当前为页高辅助连接试验版（0.4.2）。** 已实现框选 → 手动或自动滚动采集 → 分页预览和修正 → 多页 PDF 导出，并支持调整裁切、分页线、可视化标定和撤销。支持副屏可见定向滚动、提前减步、有界空白探测及独立截图保留；新增有实际像素重叠时的页高辅助连接，推算位置须检查。

## 安装与运行

Windows 11 x64 可从 [v0.4.2 预发布版](https://github.com/CharlieWinple/Visual-Document-Capture/releases/tag/v0.4.2) 下载免安装 ZIP。完整解压后双击 `VisualDocumentCapture.exe`，无需安装 Python；保留 `_internal` 文件夹，会话和日志保存在解压目录的 `sessions` 与 `logs`。程序未签名，尚未完成全新电脑及所有阅读器兼容性验收。下面是源码运行方式。

需要 Python 3.12+。开发环境使用 Python 3.13。Windows PowerShell 在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[gui,dev]"
.\.venv\Scripts\python.exe -m vdc.app.main
```

已安装依赖后，也可以双击项目根目录的 **`Start-VDC.cmd`**，或运行 `.venv\Scripts\vdc.exe`。若需要排查启动错误，使用上面的 Python 命令查看终端输出。

## 第一次体验

1. 点击「打开演示阅读器」，显示 6 页合成文档；也可以在 Chrome/Edge 打开自己的文档。
2. 点击「新建 · 框选区域」，在任意一块显示器上拖动框选。保留纸张两侧灰背景与页间空隙，避开工具栏、滚动条、浮层。拖动边缘调整，Enter 确认，Esc 取消。一次选区不跨显示器。
3. 将阅读器置于第一页顶部，点击「开始采集」。VDC 最小化后等待约 1 秒，保持阅读器可见。
4. 用鼠标缓慢滚动，也可尝试鼠标中键的匀速滚动，无需每次停顿。相邻截图应有足够重叠，出现「位置暂待确认」时降低速度。不要改变窗口位置或页面缩放。浏览器中键兼容性仍需实际体验确认。
5. 点击任务栏的 VDC 返回窗口，采集自动暂停；也可使用系统托盘菜单。点击「结束并预览」自动识别分页。
6. 点击左侧缩略图查看页面。可调整裁切、拆分页面、与下一页合并、删除；精确坐标默认收起，点击「精确调整」展开；修改自动保存。需要放大时使用预览下方按钮。
7. 点击「导出多页 PDF」选择路径。若有不完整/低置信度页或采集中断告警，先逐页检查并勾选确认框，再确认导出。

短暂匹配失败先进入「位置暂待确认」，保留最后可信位置并继续取样；超过约 1.5 秒或 24 次观察仍无法验证时暂停。回到最后成功采集位置附近，恢复采集后再缓慢前进。若无法恢复，可以结束并明确确认仅导出已有部分，或新建会话重采。未知分页会显示为**待校正内容段**，不会假称已恢复原始分页。暂停失败时在该会话的 `diagnostics/` 保留参考帧、首个和最后一个失败帧，供本地排查。

旧会话打开后点击「重新识别分页」才能应用新算法，这会替换已有分页编辑。自动识别会从至少三张完整同尺寸页面学习页高和页距；纸内空白不直接当作页间隔。必要时点击「可视化标定」，用蓝框确定完整页、橙线确定下一页顶部，自动计算页间距。推算页边仍标为待验证，需逐页检查后导出；混合尺寸文档不能强制套用统一页高。

## 直接拖拽编辑

- **调整裁切**：选中页面后点击预览下方的同名按钮。拖动蓝框四边或角点，框外显示原始内容，可向外恢复误裁部分。按「确认应用」保存，取消不改会话。
- **拆分页面**：点击分界位置放置水平线，拖动微调，确认后拆成两页。
- **可视化标定**：蓝框框住一张完整页，拖动橙色「下一页顶边」线，界面自动显示页间距，无需猜测像素数值。确认后会提示替换分页。
- 编辑器配有原始像素横纵标尺、鼠标坐标和同步数值框。滚轮缩放，拖动非边界区域平移（分页模式下可用滚动条平移）；点击边界后方向键微调 1 px，Shift 加方向键微调 10 px。
- 「展开更多原始内容」按需读取更远的相邻区域，保留当前调整；扩展后的上下文不超过 12000 行，避免一次加载整份长文档。
- 「撤销调整」或编辑器内 Ctrl+Z 撤销尚未应用的调整；主窗口「撤销已应用修改」恢复本次打开会话中的最近 20 次编辑，包括裁切、拆分、合并、删除与标定。撤销历史不会跨重启保留；换会话、重新识别或继续采集会清空历史。

编辑和撤销只修改 review.json，原始图像块保留。主窗口「精确调整」默认折叠，展开后可填写左/右边界 X、上/下边界 Y，并实时查看待应用尺寸。坐标以整条拼接长图左上角为原点，不是从四边裁掉的像素数；右、下边界不包含在保留范围内。若拖拽线太靠近，请滚轮放大后再调整。阶段说明见 `docs/VISUAL_EDITING_REPORT.md`。

会话自动保存在 `sessions/日期时间-编号/`，包含 PNG 块、`session.json`、`capture.json`、`events.jsonl` 和编辑后的 `review.json`。通过「打开已有会话」重新预览、导出或继续。继续采集前需保持相同显示布局、选区和缩放，并返回最后可信位置附近；继续采集会重新识别分页，旧编辑备份在 `review.previous.json`。停止/退出不删除已有成果。

可直接打开已有会话：

```powershell
.\.venv\Scripts\python.exe -m vdc.app.main --session output/desktop-primary-20/session
```

## 自动滚动采集

### 大面积空白（新）

**页高辅助连接：** 空白探测时，从此前已采集内容学习至少 3 张完整同尺寸页面，要求已观察到当前页顶部，随后又在截图中观察到页底与背景。只有页宽一致、推算位移仍保留至少 25%（且不少于 64 行）的实际重叠、重叠像素通过检查时，才接入当前帧。该结果是带尺寸假设的推算，不等同于有纹理的视觉定位；相关页面显示「页高连接 · 待检查」，导出前必须确认。

不补造空白、不跨过无截图覆盖的缺口；混合页高、缺少 3 页样本、纸边不明确或连接距离超出重叠范围时，仍按原规则暂停。连续空白页的页数无法保证推断。可运行 `.\.venv\Scripts\python.exe examples/blank_reader.py --height-model` 打开 4 页同尺寸样本，再正常框选体验。详情见 `docs/HEIGHT_CONNECTION_REPORT.md`。

画面下半部可定位特征减少时，自动减小输入步长。滚动后遇到无法匹配的低纹理画面，先等待渲染，再进入空白探测：最多额外发送 6 次小步滚动，探测阶段最长 12 秒。输入次数不代表像素距离；程序不会据此补白或推算页数。

直接重叠匹配成功，或满足上述页高辅助连接条件时，才继续拼接。重新出现内容但无法连接，或达到探测上限时暂停。探测期间不使用“画面不动”作为页尾完成依据。

点击「查看保留片段」打开本地 `sessions/会话/fragments/编号/`，可查看可信参考图、探测 PNG 与 manifest.json。探测截图不整批自动加入 PDF；通过连接条件的最终帧会接入长图，清单记录推算证据，其余截图仍独立保留。可以回到最后可信位置继续采集，或结束并明确确认只导出已有内容。多次探测使用不同目录，重开会话仍保留。历史独立片段的批量连接留待后续。

可选的合成空白阅读器（打开后按正常流程框选，避开窗口边框）：

```powershell
.\.venv\Scripts\python.exe examples/blank_reader.py --blank-height 900
```

该示例用于观察减步、探测和暂停行为；不能预期本版自动穿过整段 900 px 留白。详细验证范围见 `docs/BLANK_PROBE_REPORT.md`。

### 副屏可见模式（试验版）

1. 将阅读器放在副屏并保持可见，滚到文档起点；框选内容区域，保留纸边背景和页间隙，避开固定边框、工具栏和滚动条。
2. 勾选「自动滚动」，在「自动设置」选择「副屏可见（不占用鼠标和焦点，试验版）」。旧会话默认仍用前台模式。
3. 开始自动采集后，可在主屏打字、点击、滚动或切换软件。采集程序不会移动鼠标或激活阅读器。
4. **Ctrl+Shift+F8** 或系统托盘菜单可暂停。该模式下 Esc、移开鼠标或切换窗口不会暂停。继续前恢复原阅读器的可见状态与位置。
5. 完成或遇到问题时只显示托盘通知，不弹出主窗口抢焦点。点击托盘「显示窗口」查看结果、结束采集或导出 PDF。

阅读器不能最小化、移动、改变大小或被其他窗口遮住。发现这些情况会暂停；遮挡检测是采样检查，不能发现所有小浮层或阅读器内部浮层。不支持定向滚轮的阅读器会暂停，不会改用全局鼠标输入。首次始终未测到滚动也会暂停，即使画面有页底；单屏即可显示完整内容时可手动「结束并预览」。快捷键冲突时会提示暂停。

本地合成阅读器已通过副屏 200% 缩放的 6 页和 20 页实测；20 页采集期间完成 1986 次焦点/光标位置检查，均通过。**这不代表 Chrome/Edge、PDF 阅读器或所有网站已通过兼容性验收**；部分软件可能忽略消息或读取主屏操作时的修饰键状态。若不能滚动或发生缩放，先暂停，再换用前台模式。详见 `docs/VISIBLE_BACKGROUND_REPORT.md`。

### 前台模式

框选后，将阅读器滚到起点，勾选「自动滚动」，点击「开始自动采集」。主窗口最小化后有 2.5 秒准备时间，请确保阅读器在前台且选区可见。程序会将鼠标移入阅读区，滚动并验证画面；无需手动配合滚动。连续多次无位移、默认至少 6 秒且可见纸张底边后，自动结束并打开分页预览，确认后手动导出 PDF。

「自动设置」提供目标步长（视口高度的 15%–45%，默认 30%）、每步最短等待（默认 400 ms）、截图观察间隔（默认 60 ms）和末尾持续确认时间（默认 6000 ms）。步长由视觉测得的位移反馈调整；滚轮单位不等于像素，实际速度受阅读器行为和处理耗时影响。

按 Esc、移出鼠标、切换到其他窗口或恢复 VDC 窗口都会暂停。暂停后保持原阅读器和缩放，必要时回到最后可信位置附近，再点击继续采集。窗口位置/尺寸改变后应重新框选。前台模式会使用鼠标；需要同时操作其他应用时可尝试上述副屏可见模式。

匹配失败会先等待短暂渲染，之后最多两轮反向回滚和减小步长重试。只有视觉确认回到可信位置才继续；无法确认时保留已采集内容并暂停。画面不动但看不到页底也会暂停，不作为成功完成。超过确认时间的网络加载仍可能表现为末尾，必须核对最后一页；慢加载文档请调大末尾确认时间，必要时继续采集。

自动参数与完成原因保存于 capture.json，滚动步数写入本地 events.jsonl。失败图像保存于会话 diagnostics/。现有手动模式仍可使用，旧会话可继续打开。

## 自动验证命令

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\vdc-validate.exe --output output/phase0
```

不需要激活虚拟环境。重复运行时指定新的输出目录，例如 `output/phase0-run2`；验证器拒绝覆盖非空目录。所有处理均在本地执行。

如需复现已验证依赖版本，安装时添加 `-c requirements-tested.txt`。Phase 0 的 32 页离线像素回归仍通过；Phase 1 测试与真实屏幕采集结果见 `docs/PHASE1_REPORT.md`。

验证器输出：

- `REPORT.md` / `metrics.json`：定量结果、边界案例和依赖版本。
- `sample/input/source.pdf`：已知原始页图生成的测试 PDF。
- `sample/input/frames/` / `ground_truth.json`：截图序列及真实位置。
- `sample/reconstructed.pdf`：只通过截图拼接与分页生成的多页 PDF。
- `sample/session/`：可重新打开的磁盘图像块和会话清单。
- `sample/alignment.json` / `pagination.json`：位移和分页诊断。
- `fast/` / `twenty_pages/`：更快滚动及 20 页合成样本的结果。

运行安装后的 `vdc-validate --help` 可查看参数。Linux/macOS 可用 `.venv/bin/python` 与 `.venv/bin/vdc-validate` 验证算法，但目标桌面平台仍为 Windows 11。

## 算法接口

```python
from vdc.stitching.store import SegmentStore
from vdc.pagination.detector import detect_page_boundaries
from vdc.export.pdf import export_session

store = SegmentStore("sessions/demo")
for rgb_frame in frames:  # RGB uint8，尺寸保持不变
    alignment = store.add(rgb_frame)
    if not alignment.accepted:
        print(alignment.reason)  # 停止；返回最后可信位置重新获取画面
        break
else:
    pagination = detect_page_boundaries(store.iter_blocks())
    export_session(store, pagination, "output/document.pdf")
```

采集线程通过会话锁阻止同时写入。每次可信新增内容保存为 PNG 块，再原子替换清单；重启重新加载最后可信参考帧。失败帧不会更新位置。不实现首帧之前内容的前插，反向越过会话起点会报警。

## 当前限制

- 假设纵向整数位移、稳定渲染、至少 25% 视口重叠；不保证真实浏览器中的亚像素滚动、鼠标光标、固定工具栏、浮层及动态加载可匹配。
- 分页目前要求近白纸张、可区分的均匀背景和可见左右纸边，支持浅灰背景。纯白背景或裁掉纸边时无法自动确认分页；首尾不完整页面会标记并阻止默认导出。整屏完全无纹理的空白仍无法判断滚动距离，页高模型不能恢复丢失的采集内容。
- 分页置信度是启发式分值，不是成功概率。支持人工校正，但自动分页仍在结束后执行，尚未融合跨帧纸边证据；采集中不实时显示页数。
- 重复内容存在视觉不可辨识情形。即使已有重复纹理检测，也不能保证发现跳过完全相同页面。
- 已实测本地合成阅读器的真实屏幕像素采集：150% 主屏 20 页、200% 负坐标副屏 6 页。Chrome/Edge 与复杂网站 UI 尚未完成兼容性验收，不能将测试阅读器结果视为浏览器保证。
- 磁盘块避免长期持有整条文档图像，但 PDF 导出库内部内存、分页行几何的线性增长及长会话资源上限尚未做完整性能验收。
- 输出为图像 PDF，保留图像比例和像素；默认 96 DPI 只是输出尺寸约定，无法推断原 PDF 物理尺寸、矢量内容或文字层。

### 中断恢复与长文档处理

- 暂停或中断后，点击「查看恢复位置」查看最后可信截图及其在已采集长图中的像素位置。重新打开已有会话后也可查看。将阅读器滚动到相同内容、保持原缩放和窗口位置，确保画面充分重叠，再点击「继续采集」；连接仍需通过像素验证。显示的分页序号不是原文印刷页码。
- 「可视化标定」会在人工参考线附近寻找真实页边；有足够一致的多页证据时，自动修正页高、间距和周期，逐页校正位置，减少累计误差。没有视觉证据的推算页面仍标为待确认，混合尺寸页面不会强制套用。
- 会话校验、页边识别、标定、预览与导出显示处理阶段和数量，后台任务持续显示耗时；无法预估工作量的阶段显示活动进度条。
- 图片分块采用 32 MiB 上限的解码缓存，裁切从目标位置检索相关分块；同一会话内裁切修改复用已加载数据，减少重复读取和校验。

本次基准：640 像素宽的 20 页合成文档，三次运行中位数，分页识别由约 2.25 秒降至 0.91 秒。此结果用于比较相同输入下的算法开销，不代表所有真实文档的速度。


一页标定现支持未保留左右背景的截图：程序从人工指定的页间隔学习横向灰带特征，至少找到三条相符间隔才启用自动微调。周期保留小数，裁切边界逐页对齐已观察到的间隔；间隔缺失或歧义处保留待确认标记。预览会显示已验证页数与待确认页数，左右裁切仍沿用人工选择。


### 阅读与检查预览

预览默认适应宽度，长页用滚轮上下阅读；Ctrl + 滚轮以鼠标位置缩放。工具栏提供整页、100% 和缩放按钮，翻页保持当前缩放模式。按 F11 或点击「专注预览」可展开阅读空间，再次操作恢复面板。

采集设置、路径和详细警告集中在「采集设置 / 详情」，裁切、拆分、标定和坐标调整集中在「编辑工具」。左栏可跳转页码、筛选待确认页或隐藏缩略图。「检查分界」连续显示当前页底部、间隔与下一页顶部，蓝线和橙线分别标出两页的裁切位置；选择末页时检查它与前一页的分界。

新会话的自动设置默认为「副屏可见」，仍可切换前台滚动；打开已有会话时保留原先保存的模式。副屏模式要求阅读区保持可见，不会自动选择或移动阅读器到另一块屏幕。
