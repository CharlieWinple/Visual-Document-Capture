Windows x64 免安装预发布版。下载 `VisualDocumentCapture-v0.4.3-windows-x64.zip`，完整解压后运行 `VisualDocumentCapture.exe`，无需安装 Python。

本次更新：

- 修复人工一页标定后，后续页面边界逐页偏移的问题。支持没有左右背景的截图，通过实际页间隔微调，保留小数周期，并显示已验证与待确认页数。
- 新增「查看恢复位置」，显示最后可信截图和已保存位置，帮助中断后继续采集。
- 会话读取、分页识别、标定、预览和导出增加处理阶段、数量、进度条与耗时提示。
- 分批计算页边统计，增加容量受限的图片缓存与按位置检索分块，减少重复读取。

验证：100 项算法与桌面回归通过；32 页真实会话的累计边界偏移已修正，导出逐页像素比对通过。Windows 打包程序及 ZIP 解压后均通过独立进程自检，覆盖自动拼接、显示器访问、框选、预览、裁切及 PDF 导出/渲染。

自动微调需要可识别的页间隔；缺少证据的边界与首尾不完整页仍需检查。副屏采集时阅读区需保持可见。程序未签名；尚未完成另一台无 Python 电脑的兼容性验收。
