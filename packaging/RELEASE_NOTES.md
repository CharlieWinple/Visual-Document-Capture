Windows x64 免安装预发布版。下载 `VisualDocumentCapture-v0.4.5-windows-x64.zip`，完整解压后运行 `VisualDocumentCapture.exe`，无需安装 Python。

本次更新：

- 预览和导出只显示一次相同的纸边警告，保留各处原始记录。
- 框选时支持右键或 Esc 取消。
- 新建采集默认自动滚动，开始和结束按钮新增图标和悬停说明。

自动分页仍需检查未验证的边界及首尾页；副屏模式要求阅读区保持可见，不会自动移动阅读器。程序未签名，尚未完成另一台无 Python 电脑的兼容性验收。

`Source-v0.4.5.zip` 对应 main 上本次构建的源提交。免安装包包含第三方许可证与构建信息；`SHA256SUMS.txt` 用于校验下载文件。发布包不包含用户会话、调试文档和日志。
