Windows x64 免安装预发布版。下载 `VisualDocumentCapture-v0.4.4-windows-x64.zip`，完整解压后运行 `VisualDocumentCapture.exe`，无需安装 Python。

本次更新：

- 重排主界面，采集详情与编辑工具默认收起，将更多空间留给预览。
- 默认适应宽度，长页通过滚轮阅读；支持整页显示、100%、Ctrl + 滚轮缩放，翻页保留缩放模式。
- 新增 F11 专注预览、可折叠缩略图栏、页码跳转和待确认页筛选。
- 新增「检查分界」，连续显示原始页间内容与两页裁切线，方便发现误裁。
- 新会话的自动设置默认使用副屏可见模式；已有会话保留原先保存的模式。
- 包含 v0.4.3 的页间隔自动微调、中断恢复参考图、处理进度及性能优化。

本版将现有开发成果合并到 main。算法与桌面回归验证通过，打包 EXE 和 ZIP 解压后的 EXE 均通过独立进程自检，覆盖自动拼接、显示器访问、框选、预览、裁切、PDF 导出与渲染。

自动分页仍需检查未验证的边界及首尾页；副屏模式要求阅读区保持可见，不会自动移动阅读器。程序未签名，尚未完成另一台无 Python 电脑的兼容性验收。

`Source-v0.4.4.zip` 对应 main 上本次构建的源提交。免安装包包含第三方许可证与构建信息；`SHA256SUMS.txt` 用于校验下载文件。发布包不包含用户会话、调试文档和日志。
