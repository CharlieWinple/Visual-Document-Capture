# 副屏可见采集阶段报告

日期：2026-10-22。版本：0.4.0。本地分支：develop/visible-background。
上一阶段可视化编辑提交 24a1b48 已同步 GitHub main；本阶段等待用户体验确认后同步。

## 本次行为

自动设置新增「副屏可见（不占用鼠标和焦点，试验版）」。向选区中心对应的内容窗口发送 WM_MOUSEWHEEL，保留目标窗口、进程/线程标识和几何绑定；恢复时不重新绑定到其他窗口。不调用全局滚轮、鼠标移动、点击或激活窗口接口。

SendMessageTimeoutW 限制单次投递等待为 250 ms，消息不携带 Ctrl/Shift 修饰标记。投递成功后仍须通过原有视觉闭环确认位移；首次始终没有位移时暂停，避免将不支持定向滚轮误报为文档结束。仅一屏的文档可手动结束并预览。

Ctrl+Shift+F8 与托盘菜单可暂停；快捷键被占用时明确提示。主屏鼠标按键、Esc、窗口切换不触发暂停。完成或失败只发托盘通知，分页预览在后台准备，不自动激活主窗口，后台预览错误也不弹出模态框。

目标关闭、隐藏、最小化、移动、尺寸变化、子窗口替换或检测到遮挡时暂停。采用选区 5×5 采样点检查其他窗口遮挡；不能保证检测所有小浮层，也不能识别所有阅读器内部浮层。截图仍取屏幕可见像素，不支持遮挡或最小化采集。

## 尚未验收和体验建议

Chrome/Edge、独立 PDF 阅读器、复杂网页和不同权限窗口尚未通过本阶段兼容性验收。部分程序忽略定向消息，或者自行查询当前键盘状态；无法承诺所有软件下同时按 Ctrl/Shift 都不会影响阅读器。失败时暂停，不自动切换到抢占鼠标的输入方式。

先用「打开演示阅读器」放到副屏测试，再试短真实文档。选区需避开固定边框：早期原生测试框入底部约 1 像素固定边框时，分页产生碎片；缩进选区避开边框后通过，本次未宣称算法已能处理固定边框。用户框选时应保留纸边背景但避开窗口 UI。

托盘通知可能被系统免打扰设置隐藏；可随时从托盘主动打开 VDC 查看状态。末尾判定仍有远程慢加载限制，需要核对最后一页。保留前台和手动采集作为可选模式。

## 技术参考

- [WM_MOUSEWHEEL](https://learn.microsoft.com/en-us/windows/win32/inputdev/wm-mousewheel)：滚轮增量、修饰标记和有符号屏幕坐标。
- [SendMessageTimeoutW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendmessagetimeoutw)：有界消息投递。
- [RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)：线程消息队列快捷键。
