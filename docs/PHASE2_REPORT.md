# Phase 2 自动滚动采集

日期：2026-10-22；版本：0.3.0；本地分支：develop/phase-2。

Phase 1.1 已按用户授权同步 GitHub main，提交 8f76d60。本阶段新改动保留本地，等待体验确认后同步。

## 功能

自动模式使用 Windows 原生滚轮输入控制前台阅读器。先等待稳定画面，再验证视觉重叠、保存新增内容，随后才发出下一次滚动。滚轮输入量不作为像素位移；根据实际位移调整目标步长，目标默认视口高度的 30%。

界面新增「自动滚动」「自动设置」。可设置目标步长 15%–45%、每步最短等待 300–2000 ms、观察间隔 50–500 ms、末尾确认时间 4–30 秒。默认分别为 30%、400 ms、60 ms、6 秒，处理时间也会影响实际速度。参数随会话保存并在重开时恢复。

匹配失败先等待短暂渲染，随后最多进行两轮反向滚动与减半步长重试。反向输入不能保证返回原位，必须视觉确认回到可信位置。失败不会追加猜测内容；无法回滚、纯空白歧义、连续渲染变化等情况暂停并提供诊断图。

末尾确认同时要求至少四次滚动无位移、持续达到设定时间、可见纸张底边及其后的背景。未见页底则暂停。自动结束后进入现有分页预览，PDF 仍由用户检查后导出。有限等待不能证明远端文档全部加载，预览明确提示核对末页。

自动模式仅支持前台、可见窗口。绑定窗口后检查焦点、窗口位置和大小、选区中心及四角归属；鼠标移出选区、Esc、修饰键/鼠标按键、切换窗口会暂停。恢复时保持原窗口绑定，不主动抢夺焦点；用户应在准备时间内让阅读器位于前台。主窗口恢复、停止与退出也会阻止继续发出滚动指令。

## 自动化验证

累计 61 项测试覆盖原有流程和新增自动采集。最终全套运行中 60 项通过、1 项暴露窄页底背景检测问题；修正后重跑受影响的自动算法及桌面集成测试，19 项全部通过，原失败项也通过。

新增测试包括：

- 自动采集与原始画布逐像素一致、重复停留不追加。
- 滚动过头、视觉回滚、减步恢复、最多两轮重试。
- 持续加载动画有界等待，纯空白不猜测位移。
- 无位移但无页底不能成功结束；短暂延迟后继续移动会清除末尾计时。
- 窗口焦点丢失后不再发送输入、恢复与停止行为。
- 自动模式界面选项与参数落盘。
- 从主窗口启动自动采集，自动完成后显示分页与导出按钮。

## 原生桌面实测

仅操作测试进程自己的阅读器，不操作用户其他应用。20 页主屏及 6 页副屏测试先生成已知页数 PDF，再通过 PyMuPDF 渲染到测试阅读器；产品采集侧仅读取屏幕像素，不访问 PDF 内部数据。无需测试代码逐步设置滚动条，实际由产品 Windows 滚轮控制器滚动。

| 场景 | 输入指令数 | 接受帧数 | 耗时（秒） | 分页 | 最大页边误差 |
| --- | --- | --- | --- | --- | --- |
| 主屏 150%，6 页合成图，早期默认参数 | 31 | 28 | 21.324 | 6/6 | 1 px |
| 主屏 150%，20 页已知 PDF，6 秒末尾确认 | 105 | 100 | 65.842 | 20/20 | 1 px |
| 副屏 200%，负坐标，6 页已知 PDF | 33 | 28 | 25.860 | 6/6 | 0 px |

三组成功运行均无采集告警，自动结束、分页预览和 PDF 导出通过。已查看副屏结果的主窗口预览，以及 Poppler 渲染的主屏 PDF 第 20 页；页脚、双栏及中间留白可见。桌面测试验证页数、边界与最终位置，逐像素一致性由模拟输入单元测试保证，不能把桌面边界误差等同于全页像素误差。

测试过程中发现并处理两类末尾问题：副屏视口边缘可能包含一行窗口边框；单页样本只有 5 像素底部背景。检测现在忽略最外侧两行，允许最多三行阴影过渡，但仍要求至少三行连续背景证据，不放宽为“画面不动即结束”。

普通受限执行环境中的原生输入测试因前台条件不成立而暂停；在允许原生桌面交互的测试运行中完成验证。产品保留前台检查，没有跳过保护以使测试通过。

## 体验与限制

1. 双击 Start-VDC.cmd，打开演示阅读器或自己的文档。
2. 框选阅读区，保留纸张两侧与页间背景，将阅读器移至起点。
3. 勾选「自动滚动」，可按需调整自动设置，然后点击开始。
4. 在 2.5 秒准备时间内确保阅读器位于前台，等待自动预览。
5. 核对页数、首尾和失败提示，再导出 PDF。

Chrome/Edge 正式兼容性验收尚未进行。阅读器的平滑滚动、滚轮累积、整页跳转或加载行为可能导致回滚不精确，此时会暂停。完全无纹理空白仍不可定位。加载时间超过配置等待时可能被当作可见末尾，需要人工检查。窗口归属检查不能识别所有同窗口浮层。当前会使用鼠标，不支持同时在其他应用工作；后台采集属于 Phase 3。

启动脚本按用户要求保持不变。新增模块无需安装额外依赖。

## 复现与本地产物

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe examples/desktop_smoke.py --screen 0 --pages 20 --automatic --output output/phase2-new-test
```

真实输入测试会将鼠标移入自己创建的阅读器，测试期间不要操作鼠标；若阅读器被遮挡，测试拒绝发送输入。输出目录必须是新目录。

结果位于 output/phase2-auto-primary-20 和 output/phase2-auto-secondary-6-run2，包含 source.pdf、desktop.pdf、metrics.json、preview.png 和磁盘会话。图片、会话和 PDF 均不提交 Git。

实现依据：[Microsoft MOUSEINPUT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput) 的滚轮输入约定，以及 [GetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getforegroundwindow) 的前台窗口接口。
