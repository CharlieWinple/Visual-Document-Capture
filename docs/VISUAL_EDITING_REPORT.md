# 可视化编辑阶段

日期：2026-10-22；版本：0.3.1；分支：develop/visual-editing。

Phase 2 的 3e6c9b3 已同步 GitHub main。本阶段按用户要求先交付本地体验，确认后再同步；副屏可见但不占用鼠标和焦点的自动采集尚未开始实现，保留为下一阶段。

## 使用

打开已有会话，选中页面：

1. 点击预览下方「拖拽裁切」，拖动蓝框四边或角点。原始内容仍在框外显示，可向外恢复误裁内容。
2. 点击「拖动分页线」，在可见分界处点击放线并拖动，确认后拆成两页。
3. 点击「可视化标定」，用蓝框确定一张完整页，拖动橙线至下一页顶部。页高和页间距自动计算，仍会核验混合尺寸及不确定边界。

三个编辑器均提供原始像素标尺、鼠标坐标、同步数值框、滚轮缩放、适应窗口及方向键微调。Shift 加方向键为 10 像素。标定上下两条线的标签分置两侧，避免窄页间距时重叠。

编辑窗口加载当前页及其上下相邻内容，全宽保留。可点击「展开更多原始内容」异步读取更多行，不必把整份长文档拼成内存长图。一次扩展后最多 12000 行；原本选中的页面本身更大时仍按原页面加载。读取中阻止关闭，避免工作线程被提前销毁。

确认应用才修改 review.json，取消保留会话原样。主窗口原有数值裁切继续可用。原始 PNG 块不变。

## 撤销

- 编辑器「撤销调整」或 Ctrl+Z：撤销当前窗口内的拖拽、数字输入和按键微调，最多 100 次。
- 主窗口「撤销已应用修改」：恢复最近 20 次成功保存的裁切、拆分、合并、删除和标定操作，撤销结果也保存到 review.json。
- 主窗口的撤销历史只在当前打开会话期间保留，不跨重启。换会话、重新识别或继续采集会清空历史。工作线程或采集运行中不可编辑。
