# Windows 11 真实采集验收

Phase 1 已提供屏幕框选、采集与分页 UI。自带测试阅读器的双显示器采集结果见 `PHASE1_REPORT.md`；以下完整 Chrome/Edge 清单仍待执行，不是已通过记录。

1. 生成并使用已知页数的 20 页源 PDF，记录页面尺寸与页序。在 Chrome、Edge 分别打开。
2. 双击 `Start-VDC.cmd` 启动应用，新建任务并框选阅读区，左右保留背景，排除工具栏与滚动条。Enter 确认并开始，检查覆盖层隐藏，主窗口最小化。
3. 分别以 100%、125%、150% Windows 缩放测试主显示器和副显示器，记录逻辑/物理坐标；验证负坐标显示器。
4. 从第一页顶部开始手动滚动，每次保留至少一半画面。确认静止不重复保存，反向滚动不重复追加。
5. 故意快速滚过一屏，必须进入待恢复状态并提示回滚；确认恢复后正文无丢失。
6. 测试鼠标进入选区、工具栏覆盖、临时加载空白和浏览器缩放变化；失败不得生成看似完整的成果。
7. 暂停/恢复、结束/取消，强制关闭后重新打开会话，检查最后可信内容可恢复。磁盘写入失败应提示并停止。
8. 预览逐页核对首尾、页眉页脚及全部边界，调整裁切，验证拆分、合并、删除；不完整与低置信度页应高亮。
9. 导出后用独立 PDF 阅读器查看每一页，对照原文检查 20 页页数、页序、缺失、重复和比例。
10. 记录进程峰值内存、会话磁盘大小、匹配延迟和 UI 响应；持续 20 页不得出现明显内存失控。

需要保留结果：Windows 版本、显示器布局、DPI、浏览器版本、阅读器类型、源文档标识、全部告警及恢复路径。涉及实际文档的截图只保存在本地，分享前由用户选择。
