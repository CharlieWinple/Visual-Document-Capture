# Phase 1 桌面主流程交付报告

日期：2026-10-21。版本：0.2.0。结论：**已具备可运行的框选、手动滚动采集、分页预览编辑和 PDF 导出流程；这是桌面预览版，尚未完成原需求中完整的 Chrome/Edge 兼容性验收。**

## GitHub 与本次范围

Phase 0 已按用户授权推送至 GitHub `main`，提交 `d2ffc14`。本次 Phase 1 在独立本地分支 `develop/phase-1` 开发，遵循此前阶段成果确认后再同步的方式，暂不推送 Phase 1。

## 已可实际使用

- 每个显示器独立的截图覆盖层：拖拽框选、边缘调整、内部移动，Enter 确认、Esc 取消。局部逻辑坐标按该屏 DPR 转换，不缩放屏幕物理原点。
- MSS 工作线程：两次稳定观察后处理截图，忽略重复画面，只持有有限帧；主窗口最小化后采集，恢复主窗口自动暂停，Windows 原生可见性检查防止自己的控制面板进入采集。
- 开始、暂停、继续、结束预览、停止保留会话；系统托盘可显示窗口或结束采集。采集失败保留可信参考并提示回滚，恢复成功前不清除缺失风险。
- 磁盘 PNG 块、原子清单、状态日志、会话重开及最后可信位置续采；会话锁阻止两个采集线程同时写入。正常关闭等待工作线程完成，不强行销毁线程。
- 左侧页缩略图、右侧大图与缩放；数字坐标裁切、拆分、合并、删除、重新识别，修改自动落盘。
- 无可靠分页时显示明确标记的待校正内容段；残页、低置信度、人工修改、重叠和采集中断均在导出前提示，需逐页检查确认。
- 无损多页图像 PDF，按页面实际像素比例设置尺寸，临时文件成功写完后替换目标文件。
- 自带 6 页演示阅读器，可直接体验相同的屏幕采集流程。`Start-VDC.cmd` 双击启动。

## 验证结果

环境：Windows 11 build 26300，Python 3.13.0，PySide6 6.12.0，MSS 10.2.0。其余依赖见 `requirements-tested.txt`。

自动测试：**35 passed in 18.91s**。覆盖原 Phase 0 配准与 PDF 回归，以及坐标换算、稳定帧过滤、分页编辑持久化、框选拖动调整、采集线程暂停/失败/回滚恢复、静止帧不写磁盘、GUI 预览与裁切、告警导出确认、实际生成 PDF、会话锁和后台任务退出。

真实桌面测试通过自带 Qt 阅读器显示合成文档，由 MSS 读取其可见像素。测试脚本用 Qt 测试事件操作选区，移动自己阅读器的滚动条；不读取其他应用 DOM，不下载原 PDF，也不向其他应用注入鼠标滚轮。

## 实测发现并修复

1. Windows 同时读取/替换状态文件时出现短暂 `PermissionError`。增加有限重试，超过次数仍明确报告，未改为非原子的覆盖写入。
2. Qt 的逻辑屏幕宽度已取整，使用物理宽度除逻辑宽度可能产生分数 DPI 漂移。改为使用实际 DPR，并用屏内坐标换算；新增 150% 回归案例。
3. 真实截图带入一像素阅读器边框时，原分页器以侧边极差判断背景，导致整段判为不确定。改用稳健的侧边统计并排除极窄外边框；原有白背景/裁掉纸边的拒绝测试仍通过。保留失败样本于本地，未把失败隐藏成成功。
4. Qt 测试中的等待方式会占用 Python GIL，导致 Python 工作线程超时。测试改用释放 GIL 的事件泵；实际程序使用正常 `app.exec()` 事件循环。

## 尚未完成与使用边界

- Chrome/Edge、复杂网站浮层、固定工具栏、动态加载和连续平滑滚动尚未做完整实测；首次请从短文档开始，每次不超过半屏并停顿。
- 选区一次限制在一块显示器；采集时目标内容必须可见，不支持被其他窗口遮挡、最小化阅读器或后台自动滚动。
- 分页在结束后进行，尚未融合跨帧纸边证据，采集中页数不会实时更新。白纸/较暗均匀背景仍是主要适用场景。
- 裁切为数字坐标编辑，未提供可拖拽的页边裁切手柄；支持手动确认问题页，但不提供复杂的局部补采与跨片段拼接。
- 实际屏幕 20 页验证未专项测量峰值内存；100 页、高分辨率与 PDF 导出库内存仍待验收。逐块存储不意味着所有资源都达到严格常量上限。
- 仅提供无损导出，暂未加入图像压缩质量选项、临时文件清理 UI、快捷键配置、OCR 或独立 EXE。
- 无法仅凭相同像素识别所有重复页面跳转，需结合实际阅读顺序检查；截图 PDF 无法恢复原矢量、文字层或真实纸张物理尺寸。

## 使用与后续

首次体验按照 README 的桌面流程，或双击 `Start-VDC.cmd` 后使用「打开演示阅读器」。已有 Phase 0 会话没有屏幕坐标，但仍可在 UI 中预览和导出。

下一步优先做真实 Chrome/Edge 20 页验收、更多渲染/浮层/空白回归和资源测试。Phase 2 仍只保留设计：在 Phase 1 稳定后增加滚动—稳定—配准—调整步长的闭环及有限回滚，不以本次测试脚本代替产品自动采集。
