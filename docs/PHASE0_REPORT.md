# Phase 0 技术验证报告

日期：2026-10-21。阶段结论：**在限定的合成截图条件下，纵向拼接、分页和多页 PDF 导出闭环已验证；尚不能视为 Phase 1 桌面软件或真实阅读器验收通过。**

## 实际实现

工程模块、可复现测试生成器、双向纵向位移估计、静止与重复纹理检测、失败阻断、磁盘 PNG 块及原子会话清单、白纸/灰背景分页、残页标记、无损多页 PDF 和命令行验证入口。

未实现屏幕捕获、选择覆盖层、GUI、跨帧分页证据融合、人工编辑及自动滚动。用户允许阶段性交付，因此本次停在 Phase 0 里程碑；原始需求保存在 `REQUIREMENTS.zh-CN.md`，后续阶段仍保留在工程计划中。

## 方法与测量

生成器使用固定随机种子构造 RGB 页面，包含单/双栏、简单公式、表格、柱状图、页眉页脚、内部大留白，混合 440×620、500×700 和 560×430 像素纸张。背景灰度 172、白纸 255，页间距循环为 5/12/30/18 像素。测试 PDF 从这些页图生成，不是下载的原始文档。视口 640×360，各序列含静止、反向及回访。

配准器仅读取相邻截图，以纵向梯度条带的模板匹配提出候选，再验证全重叠区域像素误差与梯度误差。多峰接近则拒绝；最小重叠为视口高度的 25%。置信度为启发式分数。

分页器逐块扫描纸张侧边，按连续纸张行与背景间隔形成矩形，不按固定页高切分。整条文档像素图只由测试夹具持有，拼接器只维护一帧参考和落盘新增块。

检测器不接收位置和页数真值。评估器独立比较位移、重建像素、页面矩形；重新打开输出 PDF，提取嵌入图像并逐页比较尺寸、像素及顺序。边界指标采用精确矩形相等，未使用宽松容差。

## 失败与边界案例

|案例|观察到的结果|原因与处理|
|---|---|---|
|跨越视口、无重叠|拒绝，报告无可靠重叠|保留旧参考和位置；测试确认回滚后可恢复|
|全白画面|拒绝，即使两帧完全相同|无法证明静止，不能猜位移；目前会中断正常穿过超大空白区的采集|
|每 24 px 周期重复纹理|拒绝，报告歧义|存在多个同样可信的位移；这是可发现但无法自动解决的失败|
|同尺寸内缩放 10%|拒绝|不能以纵向平移解释，不继续累计错误|
|视口尺寸变化|拒绝|需要新选区或新片段|
|白色阅读器背景|无可靠页，输出警告|缺少纸边/背景对比，不自动猜页高|
|从页中开始、页中结束|首尾标为不完整|默认导出拒绝，等待未来 GUI 人工确认|
|模拟清单写入失败|抛出错误，旧清单可重新打开|新增孤立块可能留在磁盘，暂不自动清理用户会话|

上述前 7 项均在独立验证脚本中按预期报警/标记，后 1 项在集成测试中验证。在这些构造案例中，没有出现“检测失败且未报警”。这不是对未知场景的保证。

## 尚未解决的风险

1. 完全相同页面的跳转与静止在像素层面可能不可区分。周期条带检测并不能覆盖所有重复文档。
2. 静态工具栏、滚动条、鼠标指针、浮动按钮、局部加载、抗锯齿变化和亚像素位移尚未实测，可能造成拒绝或误配准。Phase 1 前需扩充真实截图回归集。
3. 白纸/均匀灰背景是明确的原型假设；阴影、深浅渐变背景、有色纸张、纸边被裁掉和纸内满幅图像可能干扰分页。
4. 目前没有跨帧页边验证、页面几何统计校正或人工修正工具；不能宣称满足完整 MVP 可靠性。
5. PNG 块与清单避免无限扩展的内存长图，但分页保存每行几何，PDF 库也可能缓存页面。100 页与更高分辨率需要专项测量。
6. 清单原子替换验证的是一般文件写入异常，不提供断电级持久性保证；孤立文件清理和会话校验升级留待 Phase 1。
7. 原始图像 PDF 不含矢量或 OCR 文字。图像像素不能确定原纸张物理尺寸。

## 复现与下一步

按 README 安装，运行 `python -m pytest -q` 和 `vdc-validate --output output/phase0-run2`。若在受限执行环境中无法使用系统临时目录，先创建项目 `tmp`，再指定 `--basetemp tmp/pytest-run2`。

Phase 1 的下一步是 PySide6 选区与 MSS 工作线程、有界队列、稳定帧判定、明确失败恢复状态、会话 UI 和分页编辑器。先以真实 Chrome/Edge 截图建立回归集，再实现 20 页人工滚动验收，验证步骤见 `WINDOWS_ACCEPTANCE.md`。

Phase 2 应在 Phase 1 稳定后复用配准反馈实现“滚动—稳定—匹配—调整步长”，加入回滚及有限重试，不能只用固定定时器滚动。Phase 3/4 不在本次实现范围。
