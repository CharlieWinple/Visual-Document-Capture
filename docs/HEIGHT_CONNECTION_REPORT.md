# 页高辅助连接阶段（0.4.2）

2026-10-22：空白探测版 a81b1a4 已同步 GitHub main。本阶段留在本地供体验，确认后同步。

## 可用范围

在自动采集的空白探测阶段，从已采集图像中学习至少三张完整同尺寸页。尺寸辅助连接过的页面不作为新的学习样本；已观察到的完整页面存在超过 3 像素的页高/页宽偏差时拒绝模型。要求当前未完成页有已观察的顶部背景间隔。

后续截图必须出现当前纸张的底边及至少三行背景、左右纸边与锚点一致。用“已知顶部 + 学习页高 − 当前画面中的底边位置”提出全局位置，再检查与已有参考图的重叠。至少保留 25% 视口且不少于 64 行，重叠像素平均误差不超过 1，超过 8 的像素比例不超过 0.1%。模型周期若导致重叠窗口内有多个候选，也拒绝连接。

存储层再次检查重叠，只追加当前截图中真实出现的行，不生成白色填充、不跨越未观察区。接入后的坐标仍是模型推算，置信度为启发式 0.65，必须检查，不能当作独立视觉定位确认。

这不能证明阅读器没有跳到另一张外观相同的页面；不承诺处理连续全空白页、视口之外的未知缺口、混合纸张尺寸或任意长度留白。没有模型或条件不满足时，保留原有 6 次/12 秒探测上限与暂停行为。当前不读取此前可视化标定作为自动采集模型，也不批量连接历史片段。

## 持久化与界面

session.json 原子保存 geometry_joins，包括推算位置、覆盖区间、页高/页宽/页距、样本数、锚点及 requires_review。探测目录清单记录 geometry_connected_requires_review 和连接证据；其余原始探测截图保留。

预览为受影响页面显示「页高连接 · 待检查」，重开会话/重新识别后仍从源会话证据恢复标记；修改裁切不会消除源连接记录。导出 API 同时检查源连接记录，默认拒绝未经检查的导出。GUI 沿用逐页检查勾选和告警确认流程。

## 验证与体验

完整回归 91 passed in 83.13s；另已渲染检查含「页高连接 · 待检查」标记的四页预览。

测试覆盖模型学习、混合尺寸拒绝、纸宽变化、缺少底边、重叠像素冲突、拒绝未知缺口、推算证据重开保留、预览标记和导出拦截。四页端到端合成测试从正常自动采集开始，前三页学习模型，第四页留白触发连接；检查完整长图与源图逐像素相同，并恢复四页。

```powershell
.\.venv\Scripts\python.exe examples/blank_reader.py --height-model
```

保持测试窗口的默认较矮视口，从第一页顶部框选内容，避开滚动条与窗口边框，再使用正常自动采集流程。改变视口高度可能让空白不再铺满截图，从而直接视觉匹配成功而无需页高连接；这是正常行为。
